환율 계산기

위치 기반으로 기본 통화를 잡고, 여러 나라 돈을 한 번에 환산하는 도구

환율 계산기는 브라우저 로케일로 기본 통화(예: 한국이면 KRW)를 잡고, USD 기준 실시간 환율로 교차 계산합니다. 계산기 키패드로 금액을 넣고, 보고 싶은 통화를 추가로 붙이면 됩니다.

이 도구가 하는 일

여행·송금·해외 결제 전에 “지금 이 금액이 다른 나라 돈으로 얼마인가”를 빠르게 볼 때 씁니다. 설치와 계정 없이 동작하고, 선택한 통화 목록은 이 브라우저에만 저장됩니다.

사용 방법

  1. 기본 통화. 자동으로 잡힌 통화를 확인하거나, 위쪽 버튼으로 바꿉니다.
  2. 금액 입력. 키패드 또는 키보드로 숫자를 넣고, +, −, ×, ÷ 로 간단한 계산을 할 수 있습니다.
  3. 국가 추가. 변환 결과에 달러·엔·유로 등 보고 싶은 통화를 붙입니다. 결과 줄을 누르면 그 통화가 기본 통화가 됩니다.

이 도구의 장점

  • 교차환율. API가 USD를 기준으로 줘도, 원화를 엔으로 바꿀 때 금액 × (엔 환율 / 원 환율) 로 바로 계산합니다.
  • 에이전트가 필요 없습니다. 인터넷만 있으면 브라우저에서 동작합니다.
  • 목록이 남습니다. 자주 보는 통화는 새로고침 후에도 유지됩니다.

표시 환율은 Coinbase 등의 시장 중간가이며, 은행 매매기준율·전신환·카드 수수료와 다를 수 있습니다. 송금·결제는 실제 거래 기관의 고시 환율을 확인하세요. 시세는 약 5분 단위로 다시 불러옵니다.
