다운로드 관련

Q. 다운로드가 자동으로 시작되지 않아요.
상단의 [MP3 다운로드] 버튼을 직접 눌러 주세요. 브라우저 팝업·다운로드 차단 설정을 확인해 보세요.
Q. 에이전트 연결 오류가 나요.
작업 표시줄의 itmatzip 에이전트가 실행 중인지 확인한 뒤, 환경 준비(FFmpeg 포함)를 완료해 주세요.
