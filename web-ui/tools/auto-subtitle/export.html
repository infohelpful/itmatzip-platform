Auto Subtitle

내보낸 파일, 이렇게 쓰세요

에이전트 1.7.0부터 내보낸 파일은 PC의 「다운로드」 폴더에 원본이름_AutoSubtitle 이름으로 저장됩니다. 같은 이름이 있으면 덮어쓰지 않고 (2), (3)을 붙입니다. 영상은 외부 서버로 올라가지 않고 이 PC에서만 만들어집니다.

자막 입힌 영상 (MP4)

편집 화면 미리보기에서 정한 글꼴·크기·색·배경과 강조 글자, 단어 강조가 그대로 영상에 들어갑니다. 유튜브 쇼츠·릴스처럼 자막을 화면에 새겨야 하는 곳에 바로 올릴 수 있습니다. 영상 길이와 PC 성능에 따라 몇 분이 걸릴 수 있고, NVIDIA 그래픽카드가 있으면 하드웨어 인코더로 더 빨리 끝납니다.

SRT 자막 파일 올리는 곳

  • YouTube Studio. 동영상 → 자막 → 언어 추가 → 「파일 업로드」에서 .srt를 고르고 「타이밍 있음」을 선택합니다.
  • Premiere Pro. 파일 → 가져오기로 .srt를 불러와 타임라인 위 트랙에 놓으면 캡션 트랙이 됩니다.
  • DaVinci Resolve. 미디어 풀에 .srt를 넣고 타임라인으로 끌어 놓으면 자막 트랙이 생깁니다.
  • CapCut·Vrew. 텍스트(자막) 메뉴의 「자막 파일 가져오기」로 불러옵니다.

대본 (TXT)

시간 정보 없이 문장만 줄마다 담습니다. 블로그 글·영상 설명란·회의록 초안으로 쓰거나, 다른 영상에 「대본/SRT 가져오기」로 다시 맞출 때 씁니다.

자주 묻는 질문

파일이 어디에 저장됐나요?
「폴더 열기」를 누르면 저장된 파일이 선택된 채로 탐색기가 열립니다. 브라우저로 받은 경우에는 Ctrl+J(다운로드 목록)에서 열 수 있습니다.
작업 중에 이 페이지를 닫아도 되나요?
영상은 자막 이미지를 그리는 동안 이 페이지가 필요합니다. 저장이 끝날 때까지 페이지를 닫거나 다른 곳으로 이동하지 마세요. 끝나면 「편집 화면으로 돌아가기」를 누르세요.
「에이전트에 연결할 수 없습니다」가 떠요.
작업 표시줄 트레이에서 ItMatZip 에이전트가 실행 중인지 확인하세요. 실행 중이면 「다시 시도」를 누르면 됩니다.
미리보기와 영상 자막이 달라 보여요.
편집 화면 「자막 디자인」 탭의 설정이 그대로 쓰입니다. 바꾼 뒤 다시 「내보내기」를 누르면 새 파일로 저장됩니다.
