Auto Subtitle

로컬 영상에서 자막을 뽑고 화면에서 다듬는 편집기

Auto Subtitle은 Faster-Whisper로 말소리를 글자로 바꾼 뒤, 미리보기와 자막 목록에서 타이밍·문장을 고치고 SRT나 번인 영상으로 내보내는 도구입니다. 전사 모델은 추출할 때 PC에 내려받으며, 원본 미디어는 로컬 경로만 사용합니다.

이 도구가 하는 일

왼쪽에서 영상을 재생하고, 오른쪽에서 큐 단위로 자막을 고칩니다. 폰트·크기·윤곽·워터마크를 미리보기에 반영할 수 있고, 한국어 줄바꿈은 Kiwi 형태소 분석을 쓰는 단어 자동정렬로 다듬을 수 있습니다. 클라우드 전사 서비스에 파일을 올리지 않습니다.

작업 과정

  1. 환경 준비. 에이전트 연결을 확인한 뒤, 처음이라면 모델과 런타임을 PC에 설치합니다.
  2. 미디어 불러오기. 로컬 영상 또는 오디오를 지정하면 미리보기 타임라인이 열립니다.
  3. 자막 추출. 언어와 모델 크기를 고르고 전사를 실행합니다. 결과는 큐 목록으로 쌓입니다.
  4. 교정과 보내기. 오탈자·타이밍을 고치고, SRT 또는 화면에 구운 영상으로 저장합니다. 프로젝트 저장으로 작업을 이어갈 수 있습니다.

이 도구의 장점

  • 전사와 보기가 한 화면입니다. 추출만 하고 끝나는 도구와 달리, 재생 위치에 맞춰 자막을 바로 고칩니다.
  • 한국어 줄바꿈에 신경 썼습니다. 단어 단위 정렬과 스타일 미리보기로 유튜브·강의 영상에 올리기 전 상태를 확인합니다.
  • 파일이 밖으로 나가지 않습니다. 민감한 인터뷰나 사내 영상을 외부 서버에 올리지 않고 자막을 만들 수 있습니다.

모델 다운로드와 전사는 GPU가 있으면 더 빠르지만, 에이전트가 준비된 Windows PC라면 CPU로도 진행할 수 있습니다. 작업 화면은 데스크톱 해상도에 맞춰져 있습니다.
