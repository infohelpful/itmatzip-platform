Auto Subtitle

로컬 영상에서 자막을 뽑고 단어 단위로 다듬는 편집기

Auto Subtitle은 Faster-Whisper로 말소리를 글자로 바꾸고, 단어마다 시간을 맞춘 자막 칩으로 보여 줍니다. 문장과 싱크를 고친 뒤 SRT·TXT로 저장하거나 자막을 입힌 영상으로 내보냅니다. 영상은 PC 밖으로 나가지 않습니다.

작업 과정

  1. 엔진 준비. 처음 한 번 Whisper 모델(약 1.6GB)과 FFmpeg를 PC에 받습니다. NVIDIA 그래픽카드가 있으면 GPU 런타임도 설치할 수 있습니다.
  2. 영상 선택과 자막 추출. 에이전트 파일 창에서 영상(mp4·mkv·avi)을 고르면 바로 자막을 뽑습니다.
  3. 교정. 단어 칩과 문장을 고치고, 줄을 나누거나 합치고, 필요하면 싱크를 다시 맞춥니다. 실행 취소로 되돌릴 수 있습니다.
  4. 저장과 내보내기. 프로젝트(.autosub)로 이어서 작업하고, SRT·TXT 또는 자막을 입힌 영상으로 내보냅니다.

이 도구의 장점

  • 단어 단위 싱크. 「정밀 정렬 설치」(약 2.5GB, 처음 한 번)를 하면 WhisperX로 단어 경계를 음성에 맞춥니다.
  • 미리보기 그대로 입힌 영상. 글꼴·크기·배경·외곽선·위치와 단어 강조가 미리보기와 같은 모양으로 영상에 들어갑니다.
  • 파일이 밖으로 나가지 않습니다. 인터뷰나 사내 영상도 외부 서버에 올리지 않고 자막을 만듭니다.

ItMatZip 에이전트 1.6.0 이상이 필요합니다. 작업 화면은 데스크톱 해상도에 맞춰져 있습니다.
