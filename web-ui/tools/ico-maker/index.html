ICO Maker

PNG 한 장으로 Windows용 아이콘 세트를 만드는 도구

ICO Maker는 올린 이미지를 16부터 256까지 필요한 해상도로 줄여, 크기별 ICO와 묶음 ICO를 ZIP으로 저장합니다. 서버 변환 없이 브라우저 안에서 캔버스를 그리고, Windows가 읽는 BMP 기반 ICO로 패킹합니다.

이 도구가 하는 일

파비콘, 바로가기 아이콘, 설치 프로그램용 아이콘처럼 여러 DPI에서 또렷해야 하는 정사각 그림을 다룹니다. 포함할 크기를 체크하고, 여백·자르기·늘리기 중 맞춤 방식을 고른 뒤 미리보고 받습니다. 투명 배경은 PNG 입력이 유리합니다.

작업 과정

  1. 이미지 올리기. PNG를 권장합니다. JPEG·WebP도 변환되지만 알파가 없을 수 있습니다.
  2. 해상도 선택. 16, 24, 32, 48, 64, 128, 256 중 필요한 칸만 켭니다. 원본보다 큰 크기를 만들지 않을 수도 있습니다.
  3. 미리보기. 각 픽셀 크기가 어떻게 보이는지 격자 배경에서 확인합니다.
  4. ZIP 저장. 체크한 크기마다 ICO·PNG가 생기고, 프로그램에 넣을 묶음 ICO도 함께 들어갑니다.

이 도구의 장점

  • 한 번에 여러 크기를 받습니다. 탐색기가 16×16만 보여 주더라도, ZIP 안의 파일로 각 해상도를 확인할 수 있습니다.
  • 에이전트가 필요 없습니다. 설치 없이 브라우저만으로 변환합니다.
  • Windows 아이콘 형식에 맞춰 씁니다. 작은 크기는 BMP DIB로 넣어 셸이 해상도를 고르기 쉽게 합니다.

256px보다 작은 원본을 무리해서 키우면 가장자리가 흐려집니다. 파비콘·앱 아이콘은 256px 이상 정사각 PNG를 준비하는 편이 낫습니다. 탐색기 속성 창의 크기 표시는 파일 안 실제 해상도와 다를 수 있습니다.
