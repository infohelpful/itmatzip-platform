대시보드로 이동

Windows를 설치할 때 묻는 언어, 계정, Wi-Fi를 미리 정해 두는 파일을 만듭니다.

받은 파일 쓰는 법

  1. Microsoft에서 Windows 11 설치 USB를 만듭니다. 여기서 고른 언어와 같은 설치 파일을 쓰세요.
  2. 받은 파일을 USB 맨 위에 넣습니다. 다른 폴더 안에 넣으면 적용되지 않습니다.
  3. 그 USB로 PC를 켜면, 고른 설정대로 설치가 진행됩니다.
  • 한국어로 만들었다면 영문 Windows 설치 파일은 쓰지 마세요.
  • 디스크를 자동으로 지우는 옵션을 켰다면, 고른 디스크의 파일이 전부 삭제됩니다.
  • Rufus로 USB를 만들 때 추가 설치 옵션을 켜면 이 파일을 쓰지 않을 수 있습니다.

Unattend Maker

Windows 설치 질문에 미리 답하는 파일을 만드는 도구

언어, 계정, 디스크, 지울 앱을 고른 뒤 설치 파일로 저장합니다. 컴퓨터 밖으로 올라가지 않고, 지금 쓰는 브라우저에서만 만들어집니다.

이 도구가 하는 일

Windows를 처음 설치할 때 나오는 언어, Microsoft 계정, 개인정보 화면을 건너뛰고 싶을 때 씁니다. 같은 설정을 여러 대에 반복할 때도 유용합니다. 직접 고르거나, 가정용 클린·구형 PC·미니멀로 값을 채운 다음 필요한 칸만 바꾸면 됩니다. 여기서 받은 파일은 다시 불러와 이어서 고칠 수 있습니다.

작업 과정

  1. 모드를 고릅니다. 빠르게 가려면 가정용 클린을 누르세요. 처음부터 고르려면 직접 설정을 쓰면 됩니다.
  2. 왼쪽에서 확인합니다. 계정 이름, 디스크, 지울 앱처럼 사람마다 다른 값만 보면 됩니다.
  3. 파일을 받아 USB에 넣습니다. 설치 파일 언어가 여기서 고른 언어와 같은지 확인하세요.

이 도구의 장점

  • 프리셋 후에도 전부 고칠 수 있습니다. 시작값만 채워 주고, 숨기는 옵션은 없습니다.
  • 받은 파일을 다시 열 수 있습니다. 설치에 쓰는 그 파일에 설정이 들어 있습니다.
  • 설치 프로그램이 필요 없습니다. 브라우저만으로 파일을 만듭니다.

디스크를 자동으로 지우는 옵션은 그 안의 파일을 전부 삭제합니다. 잘 모르겠으면 설치 화면에서 디스크를 고르세요. Windows 설치 USB 자체는 Microsoft에서 받아야 합니다.
