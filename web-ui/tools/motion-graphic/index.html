          모션그래픽 MP4 렌더링

          0%

          Motion Graphic

          영상과 자막만 넣으면, 설계부터 MP4 까지 한 화면에서

          내 PC의 에이전트가 영상의 화면 움직임을 재고, 내 PC의 AI(Claude Code·Codex·Antigravity)가 고른 스타일 프리셋으로 구간별 모션그래픽 설계서를 씁니다. 설계서는 고정된 장면 템플릿에 문구와 타이밍만 채우는 방식이라 빠르고, 미리보기와 최종 MP4 가 같은 코드로 그려집니다.

          1. 불러오기. 영상과 SRT 를 고르면 정지 구간·화면 급변·로고 위치를 분석합니다.
          2. 설계. 스타일 프리셋과 AI 를 고르고 ①을 누르면 FULL / OVERLAY / NONE 구간과 장면·문구·타이밍이 담긴 설계서가 나옵니다.
          3. 수정. 마음에 안 드는 구간을 고르거나 미리보기에서 그 시점으로 가서 「타이밍 0.5초 당겨줘」처럼 적으면 그 구간만 고칩니다.
          4. 적용 · 내보내기. ②로 미리보기를 확인하고 ③을 누르면 렌더가 끝날 때 알림이 뜹니다.
