관리자 설정

저장하면 방문객과 검색 크롤러에 바로 반영됩니다. 전역 광고는 모든 도구·대시보드 기본값이고, 도구에서 바꾼 광고·메타가 그 사이트만 덮어씁니다.

메뉴 표시

공개를 끄면 목록과 직접 URL이 막힙니다. 모바일은 휴대폰에서 열 수 있는지 정합니다.

전역 애드센스

모든 도구와 대시보드에 적용되는 기본 광고입니다. 도구에서 따로 저장한 칸만 그 도구 설정이 먼저 적용됩니다.

대시보드 검색 메타

검색 결과의 제목·설명입니다. 화면 카드 이름과는 별개입니다. 비우면 코드 기본값을 씁니다. 한국어 약 40자, 설명 80~160자.

법적 페이지 메타

소개·정책 등 문서의 검색 title / description / keywords입니다. 본문은 바꾸지 않습니다.

도구별 표시·검색·광고

지금 카드에 보이는 제목·부제·설명·뱃지를 칸에 채워 둡니다. 비운 칸은 저장하지 않고 기존 문구를 유지합니다. 검색 메타는 포털·SNS용입니다.
