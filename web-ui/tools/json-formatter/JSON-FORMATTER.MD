# JSON Formatter 개발 계획서

브라우저만으로 JSON을 다루고, 깨진 입력도 고쳐서 보여 주는 도구.  
jsonformatter.org류의 만능 뷰티파이가 아니라 **JSON 전문**. HTML/CSS/JS 뷰티파이·본문 추출은 이 문서 범위 밖이다.

상태: 1차 구현 (0~5단계). YAML/XML 변환은 백로그.

---

## 1. 목표

개발자가 API 응답·로그·설정 JSON을 붙여넣으면, **이 탭 안에서** 읽고, 고치고, 필요한 조각만 가져갈 수 있게 한다.

차별점은 디자인보다 아래 세 가지다.

1. 문법이 깨져도 포맷이 멈추지 않는다 (고칠 수 있으면 고치고, 무엇을 고쳤는지 보여 준다).
2. JSON 원문은 서버로 보내지 않는다.
3. 큰 문서에서 키/경로를 클릭하거나 JSONPath로 원하는 값만 뽑는다.

jsonformatter.org를 검색에서 이기려 하지 않는다. ItMatZip Tools 안의 JSON 전용 유틸로 두고, 위 세 가지가 체감되면 재방문이 생긴다.

---

## 2. 제품 범위

### 한다 (JSON만)

- 포맷(들여쓰기), 압축, 유효성 검사, 에러 위치
- 접고 펼 수 있는 트리
- 파일 열기 / 드래그 앤 드롭 / 붙여넣기 / 결과 복사·다운로드
- 깨진 JSON 자동 복구 + 변경 요약
- 민감 패턴 마스킹 (한계를 화면에 명시)
- 트리 클릭 → 경로 복사, JSONPath로 부분 추출
- TypeScript interface / Python dict 원클릭 변환

### 나중에 (같은 도구 안, JSON 인접)

- YAML 변환 (참고용, 왕복 보장 없음)
- XML → JSON (참고용)

### 하지 않는다 (명시적 제외)

- HTML/CSS/JS 포맷, Clean HTML, CSS Selector
- Java DTO, SQL CREATE TABLE, quicktype-core 브라우저 탑재 (1차)
- 에이전트·파이썬 런타임
- 그래프 시각화(JSONCrack형) — 필요하면 별 기획
- “서버 통신 0%” / “익명화 완료” / “GDPR 준수” 같은 단정 카피

## 3. 플랫폼 자리

ICO Maker·Unattend Maker·온라인 시계와 같은 **정적 웹툴**.

| 항목 | 값 |
|------|-----|
| 레지스트리 `id` | `json-formatter` |
| 경로 | `web-ui/tools/json-formatter/` |
| 런타임 | 없음 (브라우저 JS만) |
| 모바일 | 허용 후보 (`mobileEnabledToolIds`에 추가) |
| 광고 | `editorAboveWorkspace`, `editorBelowExport` (기존 슬롯) |
| 테마 | `site-runtime` 화이트 기본 / 다크 토글 |
| i18n | 온라인 시계와 같이 ko / en / ja / zh (1차는 ko+en도 가능) |

대시보드 카드 초안

- 제목: JSON Formatter
- 부제: 포맷 · 복구 · 경로 추출
- 설명: 압축된 API JSON을 브라우저에서 정렬하고, 깨진 문법도 고친 뒤 필요한 키만 뽑습니다. 원문은 이 탭을 벗어나지 않습니다.
- 뱃지: 없음 또는 `NEW` (런칭 직후만)

파이썬 `ENGINE_RUNTIME` / Go `ensureRuntimeSitePackagesDir` 작업은 **하지 않는다**.

## 4. 화면

한 화면, 두 열 (모바일은 위·아래 스택).

```
[입력] 붙여넣기 · 파일 열기          [출력] 포맷 결과 / 트리 탭
에러 또는 복구 배너
[동작] 포맷  압축  복구  마스킹  복사  저장
[추출] 경로 표시 · JSONPath 입력 · 추출 결과 패널
[변환] TypeScript  ·  Python
```

원칙

- 고급스러움은 Monaco 풀에디터가 아니라 **여백, 타이포, 에러/복구 패널, 원클릭 복사**에서 만든다.
- 입력과 출력을 한 칸에 섞지 않는다. 복구 전후를 비교할 수 있어야 한다.
- 하단 광고는 작업 영역 **아래**. 트리를 접고 펼 때 광고가 버튼에 붙지 않게 안내 블록 또는 여백을 둔다.

에디터

- 1차: 큰 텍스트 영역 + 출력 하이라이트, 또는 CodeMirror 6.
- Monaco는 번들이 커서 **보류**. 첫 페인트가 느리면 차별점보다 이탈이 먼저다.

## 5. 기술

전부 클라이언트. 파싱·복구·stringify는 **Web Worker**에서 돌린다. 메인 스레드에서 수 MB `JSON.stringify(..., 2)` 금지.

| 역할 | 선택 | 이유 |
|------|------|------|
| 복구 | `jsonrepair` | 브라우저용, 작은따옴표·트레일링 콤마·잘린 객체에 강함 |
| 느슨한 문법 | JSON5는 1차에서 **넣지 않음** | jsonrepair와 역할 중복 |
| 경로 질의 | `jsonpath-plus` | 브라우저 빌드 있음 |
| YAML | `js-yaml` (후순위) | 참고 변환만 |
| TS/Python 변환 | **자체 소량 생성기** | quicktype은 번들·Node 가정 |

용량 (원문 바이트, **사용자 PC 메모리**. 호스팅 대역폭·디스크와 무관)

20MB를 모든 기기·기능의 공통 한도로 두지 않는다. 원문 20MB는 parse + 들여쓰기 + 트리까지 가면 RAM이 몇 배로 늘어난다. 실무 JSON은 대개 수백 KB~2MB이고, 20MB는 데스크톱 포맷의 천장으로만 쓴다.

| 구간 | 동작 |
|------|------|
| 2~5MB | 막지 않음. “느려질 수 있음” 경고만 |
| 포맷·압축 | 데스크톱 **20~30MB**까지 허용 |
| 트리·JSONPath | 비싸므로 **5~8MB**에서 끄거나 텍스트 출력만 |
| 모바일 | 상한 **8~10MB** (포맷 포함) |

한도 판별은 세 가지를 **같이** 쓴다. `navigator.deviceMemory`만으로 Exact 조절하지 않는다 (없는 브라우저가 많고 값이 거칠다).

1. 좁은 화면(모바일)이면 낮은 상한
2. `deviceMemory`가 있으면 힌트로만 (예: 2GB 이하면 더 낮춤)
3. Worker 실패·타임아웃이면 “이 기기에서는 이 크기를 다루기 어렵습니다” — 입력은 유지

트리: 노드가 많으면 가상 스크롤. 전부 `details`로 그리면 멈춘다.

라이브러리는 npm 후 번들하거나, 라이선스 확인된 파일을 `vendor/`에 둔다. CDN 런타임 의존은 광고·폰트와 섞여 “원문 미전송” 설명이 흐려지므로 **복구/질의 코드는 되도록 셀프 호스트**.

## 6. 단계

각 단계가 끝나야 다음 단계로 간다. 한 단계 = 배포 가능한 상태.

### 0단계 — 뼈대 (0.5~1일)

- `index.html`, `style.css`, `script.js`, Worker 파일
- 레지스트리·sitemap·가이드 본문·광고 슬롯
- 붙여넣기, 포맷, 압축, 복사, `.json` 저장
- `JSON.parse` 실패 시 줄/위치 표시

완료: 유효한 JSON은 들여쓰기되어 복사된다. 에이전트 없이 동작한다.

### 1단계 — 복구 (핵심 차별, 1~2일)

- Worker에서 `jsonrepair` 후 다시 parse
- 복구 성공 시 배너: “N곳을 고쳤습니다” + 전/후 하이라이트(또는 요약 리스트)
- 복구 실패 시 기존처럼 에러 위치. 포맷 버튼이 빈 화면만 남기지 않음
- 원문 입력은 지우지 않음

완료: `{name: 'a',}` 같은 입력이 유효 JSON으로 정렬되고, 무엇을 고쳤는지 보인다.

### 2단계 — 트리 + 경로 (1~2일)

- 출력 탭: 텍스트 | 트리
- 키 클릭 → `$.items[0].price` 형태 경로 복사
- JSONPath 입력 → 매칭만 오른쪽(또는 하단) 패널에 포맷
- 초보자 문구: 경로 예시 칩 (`$`, `$.data[*]`, `..id`)

완료: 중첩 객체에서 클릭만으로 경로를 얻고, 질의로 부분 JSON을 복사할 수 있다.

### 3단계 — 마스킹 (0.5~1일)

감지 대상 (1차, 보수적으로)

- 이메일, 국내/국제 전화 비슷한 숫자, 카드번호 Luhn, `Bearer` / JWT 형태, `sk-`/`api_key` 값 힌트가 있는 문자열

하지 않음

- 한글 이름 추정, 주민번호 “완전 검출” 주장
- 마스킹 결과를 “익명 데이터”로 단정

카피: “흔한 패턴만 가립니다. 민감 여부는 직접 확인하세요. JSON은 이 브라우저에서만 처리됩니다.”  
애드센스·폰트가 있으므로 “이 페이지는 네트워크를 쓰지 않습니다”는 쓰지 않는다.

완료: 버튼 한 번으로 값이 치환되고, 한계가 화면에 있다.

### 4단계 — 코드 변환 (1일)

- TypeScript: 샘플에서 optional/union을 단순 추론한 `interface`
- Python: `dict` 리터럴 (타입은 후순위 TypedDict)
- 변환 실패(배열만, 빈 객체 등)는 안내하고 억지 SQL/Java는 안 만듦

완료: 포맷된 객체를 TS/Python으로 복사할 수 있다.

### 5단계 — 다듬기 (0.5~1일)

- ko/en (가능하면 ja/zh)
- 화이트/다크에서 에디터·트리 대비
- 용량 정책(경고 2~5MB, 데스크톱 포맷 20~30MB, 트리 5~8MB, 모바일 8~10MB), Worker 타임아웃
- 빈 상태, 잘못된 파일(이미지가 JSON으로 떨어진 경우)
- 도구 가이드: 로컬 처리, 복구 한계, 마스킹 한계

이후 백로그: YAML, XML→JSON, 트리 가상화 고도화, Monaco 선택 도입.

## 7. 보안·신뢰

| 사실 | 카피에 쓸 말 |
|------|----------------|
| JSON 파싱·저장은 JS 메모리 | 입력 JSON은 서버로 보내지 않습니다 |
| 광고/테마/폰트는 외부 요청 | 페이지 자체 통신과 입력 데이터를 구분해서 쓴다 |
| 마스킹은 휴리스틱 | 패턴 가리기. 법적 비식별화가 아님 |
| 복구는 원문을 바꿀 수 있음 | 원본 패널을 남기고, 고친 목록을 보여 준다 |

클립보드·파일은 ICO Maker와 같은 브라우저 `File` 흐름이면 된다. 에이전트 경로 픽은 쓰지 않는다.

## 8. 파일 구성 (예정)

```
web-ui/tools/json-formatter/
  index.html
  style.css
  script.js          # UI, 워커 호출
  format-worker.js   # parse, repair, stringify, jsonpath
  convert.js         # TS / Python (메인 또는 워커)
  i18n.js
  JSON-FORMATTER.MD  # 이 문서
```

`script.js`는 기존처럼 `adsense.js`만 import. 포맷 코어는 Worker로 격리해 UI 멈춤을 줄인다.

## 9. 일정 감각

혼자 기준, 디자인 포함 **약 1~1.5주**.  
0~1단계만 먼저 운영에 올려도 도구로 쓸 수 있다. 2~4단계는 차별점이 실제로 만져지는 구간이다.

---

## 10. 완료·품질

- 유효 JSON: 포맷·압축·복사.
- 깨진 JSON: 복구 가능하면 결과+요약, 아니면 위치 있는 에러. 입력 유실 없음.
- 메인 스레드 수 초 블록 없이 Worker 처리. 용량은 위 표대로 경고·기능 제한·기기별 상한. 실패 시 입력 유지 + 안내.
- 트리 클릭 경로, JSONPath 부분 추출.
- 마스킹은 동작하되 과대 광고 없음.
- 라이트/다크, 모바일에서 두 열이 스택되어도 복사가 가능.
- 광고 슬롯은 고정 높이 예약. 아코디언을 광고 바로 위에 붙이지 않음.

---

## 11. 리스크

- **대용량:** 탭이 죽는 가장 흔한 원인. 공통 20MB 하드캡만 두지 말고, 경고 / 포맷 상한 / 트리 상한 / 모바일을 나눈다. 호스팅 대역폭은 JSON 원문 크기와 무관하다.
- **복구 오해:** 로그 JSON을 “고쳤다”고 믿게 하면 원본 증거가 훼손된 것처럼 느껴짐 → 원문 유지가 필수.
- **마스킹 과신:** 빠져나간 PII는 제품 책임이 됨 → 문구를 약하게.
- **만능 욕심:** HTML/뷰티파이를 끼우면 CodeBeautify 복제가 됨. JSON에 머문다.
