    JSON 포맷터
    
        
    온라인 JSON 포맷터로 정렬하고 압축하기
    
        
    개발 중에 복사한 API 응답이나 설정 JSON이 한 줄로 붙어 있으면 읽기 어렵습니다. 이 페이지에 붙여넣으면 들여쓰기로 정렬하고, 필요하면 다시 한 줄로 압축합니다. 프로그램 설치는 필요 없습니다.
    
        
    JSON 포맷터가 하는 일
    
        
    JSON 정렬(Beautify), JSON 압축, 문법 오류 위치 표시, 깨진 JSON 복구, JSONPath로 값 추출, TypeScript·Python 코드 복사를 한 화면에서 합니다.
    
        
    사용 방법
    
        
      
          
    1. JSON 텍스트를 붙여넣거나 파일 열기로 .json 파일을 불러옵니다. 서버에는 올라가지 않습니다.
      2. 
          
    2. 정렬하기를 누릅니다. 안 되면 오류 고치기를 누르세요. 입력란의 원문은 그대로 둡니다.
      3. 
          
    3. 트리에서 키를 누르거나 JSONPath로 원하는 값만 복사합니다.
      4. 
          
    4. 다른 사람에게 보여 주기 전에 민감값 가리기를 쓸 수 있습니다. 모든 개인정보를 가리지는 않습니다.
      5. 
        
    
        
    이 도구를 쓰는 이유
    
        
      
          
    • 문법이 조금 깨져 있어도 멈추지 않고 고쳐서 보여 줍니다.
      • 
          
    • 큰 JSON에서도 경로만 찍어 일부만 가져갈 수 있습니다.
      • 
          
    • 별도 프로그램 없이 브라우저 탭만 열면 됩니다.
      • 
        
    
        
    가리기는 이메일·전화·카드·토큰처럼 흔한 패턴만 바꿉니다. 주민번호나 한글 이름까지 보장하지 않습니다. 광고와 글꼴은 페이지 표시용이며, 입력한 JSON과는 별개입니다.
