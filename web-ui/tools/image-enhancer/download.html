팁 & 자주 묻는 질문

다운로드 관련

Q. 다운로드가 자동으로 시작되지 않아요.
상단의 결과 이미지 다운로드 버튼을 직접 눌러 주세요. 브라우저 팝업·다운로드 차단 설정을 확인해 보세요.
Q. 에이전트 연결 오류가 나요.
작업 표시줄의 itmatzip 에이전트가 실행 중인지 확인한 뒤, 트레이에서 Image Enhancer를 다시 열어 주세요.
Q. 편집하던 작업이 사라질까 봐 걱정돼요.
편집 화면으로 돌아가기를 누르면 이전 이미지 경로와 결과 비교 화면이 복원됩니다.
🖥️

PC에서만 이용할 수 있습니다

Image Enhancer는 PC와 로컬 에이전트가 필요한 도구입니다.
