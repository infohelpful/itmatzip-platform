Thumbnail Grabber

주소만 있으면 공개 썸네일을 받아 두는 도구

Thumbnail Grabber는 유튜브 링크에서 영상 ID를 읽고, 공개된 썸네일 이미지 중에서 실제 해상도가 있는 파일만 보여 준 뒤 저장합니다. AI와 에이전트가 없고, 브라우저에서 주소 해석과 미리보기만 합니다.

이 도구가 하는 일

watch, youtu.be, Shorts, embed, live 형태의 주소를 받아 표준 썸네일 슬롯(최대 해상도부터 기본 크기까지)을 확인합니다. 비어 있는 플레이스홀더는 목록에서 걸러, 기획·아카이브·레퍼런스용으로 쓸 수 있는 이미지만 남깁니다.

작업 과정

  1. 주소 입력. 영상 URL 또는 영상 ID를 붙여 넣습니다.
  2. 썸네일 조회. 공개 이미지 주소에 실제 그림이 있는지 확인하고, 있는 화질만 카드로 나열합니다.
  3. 미리보기. 가장 큰 컷을 먼저 보고, 필요하면 다른 해상도를 고릅니다.
  4. 저장. 선택한 JPG를 로컬에 받습니다. 로그인이나 영상 다운로드는 하지 않습니다.

이 도구의 장점

  • 단계가 짧습니다. 계정 연동 없이 주소만으로 끝납니다.
  • 빈 파일을 덜 받습니다. 업로드되지 않은 고해상도 슬롯은 목록에서 제외합니다.
  • 용도가 분명합니다. 영상 파일이 아니라, 이미 공개된 커버 이미지를 자료로 보관할 때 씁니다.

썸네일 이미지의 저작권은 영상 소유자에게 있습니다. 채널 운영·레퍼런스 정리 등 권한이 있는 범위에서 사용하는 것이 맞습니다. 비공개·삭제된 영상은 이미지를 못 찾을 수 있습니다.
